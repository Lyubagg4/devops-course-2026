1. В Git ветка — это просто легкая текстовая ссылка на коммит, которая создается за секунду, а в SVN сервер буквально копирует целую кучу папок с файлами, из-за чего всё жутко виснет.

2. Без интернета в SVN закоммитить нельзя, потому что у него нет локальной базы на компе и он умеет сохранять код только напрямую на главный сервер.

3. SVN до сих пор нужен, когда в проекте куча тяжелых картинок или 3D-моделей, которые Git не вывозит, или когда надо заблокировать файл от чужих правок, чтобы никто не сломал твою работу.
